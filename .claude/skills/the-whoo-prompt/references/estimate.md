# 더 후 (THE WHOO) — PT 제작 견적

LG생활건강 더후 TR 리브랜딩 방향성 커뮤니케이션 PT 자료 제작 건. 문서는
`whoo-pt-estimate/`에 A4 2페이지 HTML로 있고, 브라우저 인쇄로 PDF를 뽑는다.

| 파일 | 내용 |
| --- | --- |
| `whoo-pt-estimate/BBB_TheWhoo_PT_Estimate.html` | 현행 (Rev.1, 2026.07.28) |
| `whoo-pt-estimate/BBB_TheWhoo_PT_Estimate_v1.html` | 최초안 (2026.07.24) |

## 현행 산정

총액 **₩8,000,000** (VAT 별도 / 합계 ₩8,800,000).

| 항목 | 산정 | 금액 |
| --- | --- | --- |
| 1차 납품 (08.03) | 10P × ₩260,000 | ₩2,600,000 |
| 2차 납품 (08.10) | 15P × ₩260,000 | ₩3,900,000 |
| 모션 그래픽 (08.10) | 2편 × ₩750,000 | ₩1,500,000 |
| 이미지 리터치 / 신규 이미지 소스 / 편집 원본 납품 | — | 포함 |

추가 요율: 추가 페이지 P당 ₩260,000, 모션 그래픽 추가 편당 ₩750,000(3~4초 기준),
유료 스톡 실비.

## Rev.1에서 바뀐 것

최초안은 레이아웃 시스템 설계가 범위에 있었고, 그래서 **1차 P당 ₩350,000 /
2차 P당 ₩300,000**의 차등 단가를 썼다. 1차에서 시스템을 구축하고 2차는 그것을
재사용하니 단가가 내려간다는 논리였다.

Rev.1에서 레이아웃 설계가 빠지고 **내용 구조화 및 도표 설계**로 대체되면서 그
차등의 근거가 사라졌다. 회차별 단가를 **균일 ₩260,000**으로 정리하고, 확보된
금액을 모션 그래픽 2편에 배정해 총액 ₩8,000,000을 유지했다.

Scope에서 `Layout System & Design` → `Content & Diagram`으로 교체하고
`Motion Graphic`을 신설했다. 2페이지 상단의 단가 설명 문구도 차등 근거에서
균일 단가 근거로 다시 썼다.

## 조건 항목

클라이언트 요청으로 **페이지 수 확정 한 줄만 남겼다** — 2차 15P 기준, 초과분은
추가 요율. 원고 전달 기준(4영업일 전), 레이아웃 기준, 모션 그래픽 수정 2회 제한,
사용 서체 조항은 모두 뺐다. 되살릴 일이 생기면 `_v1`에 원문이 있다.

계약기간은 클라이언트 확인에 따라 **2026.07.24 — 08.10**. 추가 수정 기간을
포함한 기준이다.

## 문서 손볼 때

순수 HTML/CSS 한 파일이고 외부 의존성이 없다. A4 기하는 상단 주석에 적혀 있는데,
`.page`의 `min-height`가 297mm가 아니라 **296mm**인 것은 브라우저 반올림 오차로
장마다 빈 페이지가 끼는 것을 피하기 위한 것이니 건드리지 말 것.

금액을 고칠 때는 세 곳이 함께 움직인다 — 1페이지 `Project Amount`, 2페이지
quote-table의 각 행과 `sum-row`, 그 아래 `sum-area`의 공급가/부가세/합계.
Additional Charges의 추가 페이지 단가도 본 단가와 어긋나지 않는지 확인한다.
